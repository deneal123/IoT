# 5-уровневая архитектура: Умный многофункциональный стадион (UMS)

Домен: стадион на 45–60k мест, крыша-трансформер, матчи/концерты/массовые мероприятия.

## Уровень 1 — устройства (field/edge)
- Безопасность и доступ: турникеты с NFC/QR/RFID, биометрические терминалы (лицо/ладонь), смарт-замки служебных помещений, металлодетекторы, считыватели карт.
- Окружение: датчики CO₂/PM2.5/температура/влажность, шумомеры, вибрация (трибунные конструкции), ветровые и снеговые датчики для крыши, уровень освещенности, погодная станция.
- Инженерия: смарт-счетчики электро/вода/тепло/газ, датчики протечек, термостаты, актуаторы клапанов HVAC, частотники вентиляторов, PDU/UPS телеком.
- Видео и аналитика: IP-камеры (периметр, трибуны, проходы), PTZ-камеры, тепловизоры (очереди/безопасность), bodycam персонала.
- Транспорт и мобилити: зарядные станции для электрокаров (ЭЗС), парковочные датчики, BLE-маяки навигации внутри стадиона, умные светофоры на выезде.
- Медицинский блок: телеметрия дефибрилляторов (AED), датчики наличия аптечек, браслеты волонтеров.
- Кейтеринг и ритейл: смарт-весы, холодильники с телеметрией, кассовые терминалы с сканерами штрих/QR.
- Сцена/игровое поле: датчики состояния газона (влага/температура), управление прожекторами, механика крыши.
- Дополнительно: Промышленные датчики вибрации/температуры на оборудовании (станки для поля, генераторы), PLC (программируемые логические контроллеры) для управления механизмами крыши, edge-шлюзы с локальной обработкой (фильтрация, агрегация данных).
- Условия: Экстремальные (вибрация трибун, влажность, перепады температуры) — стандарты защиты IP65+.

## Уровень 2 — подсистемы
- СКУД и периметр: турникеты, шлагбаумы, домофоны, замки, биометрия.
- ОПС/СОУЭ: пожарные извещатели, ручные извещатели, клапаны дымоудаления, оповещение и эвакуация.
- ВК/ОВ/Эл-ка: HVAC (чиллеры, вентиляция, отопление), насосные, ИБП/ДГУ, освещение (арена/коридоры/фасад), энергосбережение.
- Видеонаблюдение и видеоаналитика: VMS + модули подсчета людей, распознавание аномалий/скоплений, трекинг очередей.
- Навигация и RTLS: BLE, UWB для персонала/инвентаря, внутренние карты.
- Парковка и ЭЗС: управление местами, тарифами, бронированиями, телеметрия зарядок.
- Ритейл/кейтеринг: POS, склад, «умные» витрины, мониторинг очередей.
- Газон и сцена: агромониторинг, управление освещением поля, механика крыши и штор, безопасность работы механизмов.
- Медицинская безопасность: мониторинг AED, тревожные кнопки, локальные диспетчерские.
- Дополнительно: MES для управления "производством" (обслуживание поля, кейтеринг как конвейер), интеграция с SCADA для энергосистем.
- Протоколы: Profinet для промышленных сетей, CAN для механизмов.

## Уровень 3 — BMS/АСУЗ²
- Единый диспетчерский слой: SCADA/BMS для интеграции подсистем, сценарии (матч/концерт/эвакуация/ночной режим), тайминг-шаблоны.
- Шины и интеграции: BACnet/IP, Modbus TCP/RTU, OPC UA, ONVIF, SNMP, OCPP (ЭЗС), MQTT/LwM2M для edge-датчиков.
- Цифровой двойник объекта: топология, паспорта оборудования, KPI инженерии и эксплуатации.
- SLA и инциденты: корреляция событий (видео+СКУД+датчики), журнал тревог, роли и подтверждения.
- Дополнительно: Цифровые двойники физических активов (моделирование износа оборудования), предиктивная аналитика (ML для предсказания поломок), интеграция с ERP для учета ресурсов.
- Сценарии: Добавлены режимы "Предиктивное обслуживание", "Энергооптимизация".

## Уровень 4 — Платформа + клиентские приложения
- Платформа (backend): микросервисы (AuthN/AuthZ, Tickets, Parking, Retail, Navigation, VideoAI, Energy, Safety, Maintenance), API Gateway, шина событий (Kafka/NATS), time-series (TimescaleDB/InfluxDB), объектное хранилище (S3), БД (PostgreSQL), очереди (RabbitMQ), CEP для правил.
- Приложения:
  - Mobile App (болельщик/посетитель): e-ticket, навигация по стадиону, push-оповещения, заказ еды к месту, AR-навигация, вызов помощи, интеграция с MAX для уведомлений.
  - Web-кабинет организатора/арендатора: дэшборды спроса, очереди, энергопотребление, SLA, бронирования площадей.
  - Приложение диспетчера (толстый клиент или web desktop): карты, тревоги, управление сценариями, ручное вмешательство.
- Безопасность: IAM (RBAC/ABAC), SCIM, журнал аудита, KMS/HSM, E2E для команд управления критичной механикой (MFA).
- Дополнительно: Edge-ноды для локальной аналитики, облако для big data (анализ трендов), интеграция с MES/ERP.
- Микросервисы: Добавлены Maintenance (обслуживание), Analytics (предиктивная).

## Уровень 5 — Внешние системы
- MAX: отправка e-ticket, обновления статуса мероприятия, массовые и таргетированные уведомления, чат поддержки.
- Госуслуги (ЕПГУ): проверка цифрового ID, льготы, контроль возрастных ограничений, электронные разрешения на массовые мероприятия.
- GR/надзор: передача показаний АСКУЭ/ресурсов, отчеты по безопасности, инцидентам, доступам; подключение к городским системам видеонаблюдения при необходимости.
- Платежные провайдеры и банки: эквайринг, возвраты, split для арендаторов.
- Страховые и медицинские сервисы: быстрый доступ к полисам и маршрутизация пострадавших.
- Дополнительно: SCM (управление цепочками поставок для инвентаря), CRM (управление клиентами/арендаторами), городские системы (транспорт, экология).

### Карта протоколов и шин
- Полевые/промышленные: BACnet/IP, Modbus TCP/RTU, OPC UA, KNX, DALI (освещение), DMX (сцена), CAN (механизмы).
- IoT/edge: MQTT 5.0 (TLS), LwM2M/CoAP, BLE, Zigbee, Thread, LoRaWAN (вне помещений), WebRTC для камер bodycam.
- Видеослой: ONVIF/RTSP(S), SRT для низких задержек, HLS/DASH для клиентов.
- Зарядки: OCPP 1.6/2.0.1.
- Безопасность транспорта: TLS 1.3, mTLS, OAuth2.1/OIDC, ACME для сертификатов, JWS для команд.
- Новые протоколы для IIoT: Profinet: Для промышленных сетей, детерминированная передача; TSN (Time-Sensitive Networking): Гарантированная задержка для реального времени; EtherCAT: Высокоскоростная сеть для управления роботами/механизмами.

### Режимы (сценарии BMS верхнего уровня)
- Матч: максимальная пропускная способность входов, предпрогрев HVAC, освещение поля, анти-скопления.
- Концерт: сцена/DMX/звук, отключение части трибун, усиление контроля очередей.
- Ночной/энергосбережение: минимальный HVAC и свет, охрана периметра, отложенные работы.
- Эвакуация: автоматическое оповещение, маршрутизация потоков, разблокировка выходов (в рамках норм), приоритетные каналы связи.
