# UI: мобильное приложение посетителя и веб-кабинет организатора

Выбор: Mobile (iOS/Android) для посетителя + Web для организаторов/диспетчеров.

## Экран 1 — Билет и вход (Mobile)
См. вайрфрейм: `ui/ticket.svg`

- Элементы: QR/e-ticket (динамический), кнопка NFC-pass, индикатор места (сектор/ряд/место), кнопка «Навигация до входа», тумблер «Биометрия добровольно».
- Состояния:
  - Нормальный: активный вращающийся QR с TTL 30 сек.
  - Оффлайн: оффлайн-токен с подписью, предупреждение о возможной проверке вручную.
  - Ошибка/бан: красная плашка «Билет недействителен/уже использован» + CTA «Помощь».
- Доступность: контрастность ≥ 4.5:1, крупные кнопки, поддержка экранных дикторов (aria-label для QR и NFC).
- Потоки:
  - «Показать билет» -> авто-яркость (если разрешена) + таймер QR.
  - «NFC-pass» -> анимация прикладывания, fallback на QR.
  - «Навигация до входа» -> переход на карту (Экран 2).

## Экран 2 — Навигация и анти-скопления (Mobile)
См. вайрфрейм: `ui/navigation.svg`

- Элементы: интерактивная карта, тепловая карта плотности, список маршрутов с ETA, маркеры «Вы здесь» и «Сектор».
- Состояния: маршрут 1/2, перегрузка участка (красная зона), автообновление при изменении плотности.
- Ошибки: недоступен indoor-локатор → предложить статическую схему и указатели.
- Доступность: цветовые индикаторы дублируются иконками/текстом (на случай дальтонизма).

## Экран 3 — Ритейл/еда к месту (Mobile)
См. вайрфрейм: `ui/food.svg`

- Элементы: меню, карточки блюд с ценой, «В корзину», «Оформить», статус заказа с ETA/окном.
- Состояния: ожидание оплаты, успешная оплата, в пути, готово к выдаче.
- Ошибки: платеж отклонён → повтор/сменить метод; блюдо недоступно → показать аналоги.
- Доступность: фокусные состояния для клавиатуры, озвучивание изменений статуса.

## Экран 4 — Тревога и помощь (Mobile)
См. вайрфрейм: `ui/sos.svg`

- Элементы: большая кнопка SOS, тип инцидента, моя позиция (сектор/ряд/место), инструкции.
- Состояния: SOS отправлен (идентификатор заявки), обратная связь от диспетчера (чат/пуш).
- Ошибки: нет сети → SMS-шаблон/офлайн-квитирование на входе.

## Доработки для ДЗ2: новые экраны для предприятия

### Экран 5 — Предиктивное обслуживание (Web)
См. вайрфрейм: maintenance-dashboard.svg (на основе web-dashboard.svg)

- Элементы: Карта оборудования, индикаторы состояния (зеленый/желтый/красный), графики предсказаний поломок, кнопка «Запланировать обслуживание».
- Состояния: Активные алерты, история ремонтов.
- Доступность: Фильтры по типу оборудования, экспорт отчетов.

### Экран 6 — Управление складом (Web)
См. вайрфрейм: inventory-dashboard.svg

- Элементы: Уровни запасов, заказы поставок, RFID-сканер симуляция.
- Состояния: Дефицит (красный), оптимально (зеленый).
- Доступность: Интеграция с MES, уведомления о пополнении.

### Экран 7 — Экологический мониторинг (Web)
См. вайрфрейм: eco-dashboard.svg

- Элементы: Графики CO2/энергии, рекомендации по оптимизации.
- Состояния: Превышение норм (алерт).
- Доступность: Связь с GR, экспорт данных.
