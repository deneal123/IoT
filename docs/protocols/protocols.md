# Принцип работы и протоколы

## Принцип работы (в 2–3 слайда)
1) Сбор данных и управление на краю
- Датчики/актуаторы уровня 1 подключены к контроллерам/шлюзам подсистем уровня 2 (HVAC, СКУД, VMS и пр.).
- Протоколы полевого уровня: BACnet/Modbus/KNX/DALI/DMX/BLE/Zigbee/Thread/LoRaWAN — в зависимости от среды.
- Локальные правила (edge) для низкой задержки: эвакуация, анти-скопления, защита механизмов крыши.

2) Интеграция подсистем в BMS/АСУЗ²
- Единый диспетчерский контур: SCADA/BMS агрегирует телеметрию в реальном времени, управляет сценариями (Матч/Концерт/Ночь/Эвакуация).
- Интеграции: OPC UA, BACnet/IP, Modbus TCP, ONVIF для камер, OCPP для зарядок, MQTT для датчиков.
- CEP/Правила: корреляция событий (видео+СКУД+датчики) для автоматических реакций.

3) Платформа и клиенты
- Backend микросервисы через API Gateway и шину событий (Kafka/NATS). Хранение: time-series (Influx/Timescale), объектное (S3), реляционное (PostgreSQL).
- Клиенты: Mobile App (посетитель), Web (организатор/диспетчер), интеграции с MAX и ЕПГУ, отчётность в GR.
- Безопасность: IAM (OIDC/OAuth2.1), mTLS для машинных интеграций, трейсинг/аудит.

## Используемые протоколы
- Транспорт и шины: MQTT 5.0 (QoS, Retain, Shared Subscriptions), NATS/Kafka, WebSocket.
- Промышленные: BACnet/IP, Modbus TCP/RTU, OPC UA, KNX, DALI, DMX, CAN.
- Видео: RTSP(S), ONVIF, SRT, HLS/DASH.
- Зарядная инфраструктура: OCPP 1.6/2.0.1.
- Идентификация/доступ: OIDC, OAuth 2.1, FIDO2/WebAuthn, SCIM.
- Криптография/безопасность: TLS 1.3, mTLS, JWS/JWT, ACME/Let's Encrypt для внешних, частный PKI для внутренних.
- Edge IoT: LwM2M/CoAP, BLE, Zigbee, Thread, LoRaWAN.

## Потоки данных (пример)
- Камеры -> VMS (RTSP/ONVIF) -> Видеоаналитика -> События (MQTT) -> CEP -> BMS -> Клиенты (Web/Mobile/MAX).
- СКУД -> BMS (BACnet/OPC UA) -> Платформа Tickets -> Mobile e-ticket/MAX.
- АСКУЭ -> Платформа Energy (Modbus/BACnet) -> Отчеты -> GR.
