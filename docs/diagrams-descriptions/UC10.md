# Описание диаграммы UC10: Бизнес-аналитика и отчетность для менеджмента

## Общее описание
Диаграмма показывает сценарий бизнес-аналитики на стадионе, эволюционировавший к IIoT-предприятию. Включает сбор данных из всех подсистем, расчет KPI (OEE, ROI), генерацию дэшбордов и отчетов для принятия решений.

## Переход от стадиона к уровню предприятия
Изначально — простые отчеты для стадиона. В IIoT-версии:
- Big data аналитика из всех источников (IoT, OT).
- Предиктивные KPI (OEE — overall equipment effectiveness).
- Интеграция с ERP для бюджетирования.
- Реал-тайм дэшборды для менеджмента.
- ML для прогнозов ROI мероприятий.
Это отражает переход к data-driven предприятию с фокусом на ROI и оптимизацию.

## Детальное описание диаграммы
Потоковая диаграмма с аналитическими элементами.

### Визуальные элементы
- **Подсистемы**: Блоки (СКУД, HVAC, etc.) с иконками. Источники данных.
- **Аналитика**: Блок с графиками. Рассчитывает KPI.
- **Дэшборды**: Экран с диаграммами. Для менеджмента.
- **Менеджмент**: Иконка людей. Принимают решения.
- **ERP**: Блок с отчетами. Для учета.

### Потоки данных и связи
1. **Сбор**: Стрелки от подсистем к аналитике (Kafka/NATS).
2. **Расчет KPI**: Внутренний поток в аналитике.
3. **Генерация**: Стрелка к дэшбордам (WebSocket).
4. **Решения**: Стрелка к оптимизации (API).
5. **Интеграция**: Стрелка к ERP (SOAP).

### Цветовая схема и состояния
- Зеленый: Положительные KPI.
- Желтый: Нейтральные.
- Красный: Низкие, корректировка.
- Синий: Данные и отчеты.

### Ключевые особенности IIoT
- **Big data**: Обработка больших объемов от IoT.
- **Предиктивность**: ML для прогнозов.
- **Интеграция**: С ERP для end-to-end видимости.
- **Безопасность**: RBAC для доступа к данным.
- **Реал-тайм**: Для оперативных решений.
