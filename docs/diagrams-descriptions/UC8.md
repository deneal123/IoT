# Описание диаграммы UC8: Экологический мониторинг и энергоэффективность

## Общее описание
Диаграмма представляет сценарий экологического мониторинга и оптимизации энергопотребления на стадионе, эволюционировавший к IIoT-уровню предприятия. Включает сбор данных о CO₂, PM2.5 и энергии, реал-тайм оптимизацию HVAC/освещения и отчетность для соответствия нормам и снижения затрат.

## Переход от стадиона к уровню предприятия
Изначально — базовый мониторинг для комфорта посетителей. В IIoT-версии:
- Edge-аналитика для мгновенной оптимизации (HVAC, освещение).
- Предиктивные модели для пиковых нагрузок (ML).
- Интеграция с городскими системами экологии.
- Отчеты в GR для прозрачности и штрафов.
- Цифровые двойники для моделирования энергопотребления.
Это отражает переход к устойчивому предприятию с фокусом на ESG (экология, социальная ответственность, управление).

## Детальное описание диаграммы
Потоковая диаграмма с экологическими и энергетическими элементами.

### Визуальные элементы
- **Датчики CO₂/PM2.5/энергии**: Круги с иконками (CO₂, энергия). Расположены на уровне устройств.
- **Edge-аналитика**: Блок с иконкой процессора. Оптимизирует в реальном времени.
- **BMS**: Центральный блок, применяет модели.
- **Платформа Energy**: Облачный блок с графиками. Формирует отчеты.
- **GR (Государственный реестр)**: Блок с иконкой документов. Получает отчеты.
- **Городские системы**: Иконка города. Обратная связь.

### Потоки данных и связи
1. **Сбор**: Стрелки от датчиков к edge (MQTT/LwM2M).
2. **Оптимизация**: Двунаправленные стрелки к HVAC/освещению (BACnet/Modbus).
3. **Моделирование**: Стрелка от BMS к платформе (OPC UA).
4. **Отчеты**: Стрелка к GR (API с TLS).
5. **Интеграция**: Стрелка к городским системам (WebRTC/ONVIF).

### Цветовая схема и состояния
- Зеленый: Нормальные уровни, энергоэффективность.
- Желтый: Превышение, корректировка.
- Красный: Критическое превышение, алерт.
- Синий: Команды оптимизации.

### Ключевые особенности IIoT
- **Реал-тайм**: TSN для гарантированной задержки в управлении.
- **Предиктивность**: ML для прогноза нагрузок.
- **Интеграция**: С городскими сетями для синергии.
- **Безопасность**: Zero Trust для доступа к данным экологии.
- **Устойчивость**: Фокус на снижение углеродного следа.
