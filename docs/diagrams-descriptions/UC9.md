# Описание диаграммы UC9: Интеграция с городскими системами

## Общее описание
Диаграмма иллюстрирует сценарий интеграции стадиона с городскими инфраструктурными системами, адаптированный для IIoT-предприятия. Включает обмен данными о трафике, погоде и парковке для улучшения навигации, управления ЭЗС и синергии с городом.

## Переход от стадиона к уровню предприятия
Изначально — изолированный IoT для стадиона. В IIoT-версии:
- API-интеграция с городскими системами (транспорт, экология).
- Корреляция данных для оптимизации маршрутов и ЭЗС.
- Уведомления посетителям о пробках/альтернативах.
- Обратная связь в городские системы (данные о событиях).
- Цифровые двойники для моделирования городской интеграции.
Это отражает переход к "умному городу" с предприятием как частью экосистемы.

## Детальное описание диаграммы
Потоковая диаграмма с элементами городской интеграции.

### Визуальные элементы
- **Городские API**: Блок с иконкой города. Предоставляет данные трафика/погоды.
- **BMS**: Центральный блок, коррелирует данные.
- **Платформа Integration**: Облачный блок с картами. Обновляет маршруты.
- **Посетители**: Иконка людей. Получают уведомления.
- **ЭЗС (Электрозарядные станции)**: Иконка зарядки. Управление тарифами.
- **Обратная связь**: Стрелка к городским системам.

### Потоки данных и связи
1. **Получение данных**: Стрелки от городских API к BMS (REST/GraphQL).
2. **Корреляция**: Стрелка к парковке/навигации (OPC UA).
3. **Обновление**: Стрелка к платформе (MQTT).
4. **Уведомления**: Push к посетителям (WebSocket).
5. **Управление ЭЗС**: Стрелки к зарядкам (OCPP).
6. **Обратная связь**: Стрелка к городу (API).

### Цветовая схема и состояния
- Зеленый: Нормальный трафик.
- Желтый: Задержки, альтернативы.
- Красный: Пробки, перенаправление.
- Синий: Команды управления.

### Ключевые особенности IIoT
- **Интеграция OT/IT**: BMS как мост к городским IT-системам.
- **Реал-тайм**: TSN для синхронизации с городским транспортом.
- **Безопасность**: mTLS для внешних API.
- **Масштабируемость**: Поддержка множественных интеграций.
