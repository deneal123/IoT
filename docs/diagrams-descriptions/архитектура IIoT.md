# Описание диаграммы Архитектура IIoT

## Общее описание
Диаграмма представляет 5-уровневую архитектуру умного стадиона, эволюционировавшую от IoT к IIoT-предприятию. Включает уровни от устройств до внешних систем, с фокусом на интеграцию OT/IT, edge-вычисления и цифровые двойники.

## Переход от стадиона к уровню предприятия
Изначально — 4-уровневая архитектура для потребительского IoT. В IIoT-версии:
- Добавлен уровень цифровых двойников и MES.
- Edge-обработка для надежности.
- Интеграция с ERP/MES для enterprise-функций.
- Zero Trust и промышленные протоколы (Profinet, TSN).
- Фокус на кибербезопасности и отказоустойчивости.
Это отражает переход к промышленному уровню с OT/IT-конвергенцией.

## Детальное описание диаграммы
Иерархическая диаграмма с 5 уровнями, стрелками связей.

### Уровни
1. **Уровень 1 — Устройства**: Круги/прямоугольники для датчиков, PLC, edge-шлюзов. Протоколы: Modbus, Profinet.
2. **Уровень 2 — Подсистемы**: Блоки HVAC, СКУД, VMS. Интеграция через BMS.
3. **Уровень 3 — BMS/SCADA**: Центральный блок с CEP. Цифровые двойники.
4. **Уровень 4 — Платформа**: Микросервисы, API Gateway. Maintenance, Analytics.
5. **Уровень 5 — Внешние системы**: MAX, ЕПГУ, GR, ERP.

### Связи
- Вертикальные стрелки: Потоки данных (MQTT, OPC UA).
- Горизонтальные: Интеграции (BACnet, Modbus).

### Цветовая схема
- Серый: Устройства.
- Синий: Подсистемы.
- Зеленый: BMS.
- Оранжевый: Платформа.
- Красный: Внешние.

### Ключевые особенности IIoT
- **Edge**: Локальная обработка.
- **Цифровые двойники**: Моделирование.
- **Безопасность**: mTLS, IAM.
- **Протоколы**: Profinet, TSN, EtherCAT.
