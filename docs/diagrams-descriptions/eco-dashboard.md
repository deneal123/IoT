# Описание диаграммы Eco-dashboard

## Общее описание
Диаграмма представляет веб-дэшборд экологического мониторинга для IIoT-стадиона. Включает графики CO₂, энергии, рекомендации по оптимизации и связь с GR.

## Переход от стадиона к уровню предприятия
Изначально — простой мониторинг. В IIoT-версии:
- Реал-тайм данные от датчиков.
- Предиктивные рекомендации (ML).
- Интеграция с GR для отчетности.
- Фокус на устойчивость и compliance.
Это отражает enterprise-подход к экологии.

## Детальное описание диаграммы
Макет веб-интерфейса с элементами.

### Элементы
- **Графики CO2/энергии**: Линейные диаграммы.
- **Рекомендации**: Панель с советами.
- **Алерты**: Красные индикаторы превышений.
- **Экспорт**: Кнопка для GR.

### Связи
- Данные от BMS/платформы.
- Вывод в GR.

### Цветовая схема
- Зеленый: Норма.
- Красный: Превышение.

### Ключевые особенности IIoT
- **Реал-тайм**: Обновление данных.
- **Аналитика**: ML-рекомендации.
- **Интеграция**: С внешними системами.
