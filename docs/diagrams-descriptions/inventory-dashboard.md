# Описание диаграммы Inventory-dashboard

## Общее описание
Диаграмма показывает веб-дэшборд управления складом для IIoT-стадиона. Включает уровни запасов, заказы поставок, RFID-симуляцию и интеграцию с MES.

## Переход от стадиона к уровню предприятия
Изначально — ручной учет. В IIoT-версии:
- Автоматический мониторинг датчиков.
- Предиктивные заказы.
- RFID для трекинга.
- Интеграция с MES/ERP.
Это отражает enterprise-логистику.

## Детальное описание диаграммы
Макет с панелями.

### Элементы
- **Уровни запасов**: Бар-чарты.
- **Заказы**: Список с статусами.
- **RFID**: Симуляция сканера.
- **Уведомления**: О дефиците.

### Связи
- Данные от датчиков/MES.
- Команды к персоналу.

### Цветовая схема
- Зеленый: Оптимально.
- Красный: Дефицит.

### Ключевые особенности IIoT
- **Автоматизация**: RFID.
- **Аналитика**: Спрос.
- **Интеграция**: MES.
