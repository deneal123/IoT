# Описание диаграммы Maintenance-dashboard

## Общее описание
Диаграмма представляет веб-дэшборд предиктивного обслуживания для IIoT-стадиона. Включает карту оборудования, индикаторы состояния, графики поломок и планирование.

## Переход от стадиона к уровню предприятия
Изначально — реактивное обслуживание. В IIoT-версии:
- Предиктивные модели ML.
- Цифровые двойники.
- Автоматическое планирование.
- Интеграция с MES.
Это отражает enterprise-подход к надежности.

## Детальное описание диаграммы
Макет с картой и графиками.

### Элементы
- **Карта оборудования**: Интерактивная карта.
- **Индикаторы**: Зеленый/красный статус.
- **Графики**: Предсказания поломок.
- **Кнопка планирования**: Для обслуживания.

### Связи
- Данные от датчиков/BMS.
- Команды к техперсоналу.

### Цветовая схема
- Зеленый: Норма.
- Красный: Поломка.

### Ключевые особенности IIoT
- **Предиктивность**: ML.
- **Цифровые двойники**: Моделирование.
- **Интеграция**: MES.
