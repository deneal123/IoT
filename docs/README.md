# Комплексное IoT-решение: Умный многофункциональный стадион (UMS)

Этот репозиторий содержит материалы к презентации и защите проекта по проектированию IoT-системы. Выбранный домен — умный многофункциональный стадион (не ЖК/квартира/город).

Состав:
- 5-уровневая архитектура
- 5 бизнес-сценариев (use cases) + текстовые диаграммы для воссоздания
- UI (mobile/web) — минимум 3 экрана
- Принципы работы и протоколы
- Таблица уязвимостей и мер нейтрализации
- Структура слайдов презентации
- Текст спикера (до 5 минут)

Сторонние внешние сервисы в интеграциях:
- MAX (мессенджер) — стороннее мобильное приложение
- Госуслуги (web/mobile) — ЕПГУ
- GR — государство (учет ресурсов, надзор деятельности УК, безопасность)
