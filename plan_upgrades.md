# План доработок проекта для ДЗ2: переход к уровню предприятия с IIoT

## Цель
Укрупнить систему до размеров предприятий, учесть специфику IIoT: надежность, отказоустойчивость, edge computing, интеграция OT/IT, безопасность (Safety), разнообразие сетей, бизнес-модели XaaS. Разработать архитектуру на 5 уровней, 5 сценариев, описать работу с оборудованием, протоколы, дополнить уязвимости. Добавить 5-10 новых слайдов в презентацию.

## Основные изменения
- **Масштаб**: Стадион как предприятие: управление инфраструктурой, предиктивное обслуживание, интеграция с ERP/MES, цифровые двойники.
- **Оборудование IIoT**: Добавить промышленные активы: станки для обслуживания поля, HVAC системы, энергогенераторы, конвейеры для кейтеринга.
- **Архитектура**: Адаптировать уровни под IIoT: edge для реального времени, OT/IT интеграция, облако для аналитики.
- **Сценарии**: Модифицировать существующие и добавить новые под предприятие.
- **Безопасность**: Дополнить уязвимости специфичными для IIoT.
- **Презентация**: Добавить новые слайды в конец, создать план.
