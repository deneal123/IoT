# Новые диаграммы для ДЗ2

Все новые диаграммы и UI созданы путем копирования и детальной модификации существующих файлов с помощью Python скриптов redesign_svgs.py и redesign_ui.py. Заменены все текстовые метки, описания и элементы интерфейса для соответствия новым сценариям IIoT.

## Диаграммы (docs/diagrams/)
- **UC6 Мониторинг и предиктивное обслуживание оборудования.svg**: Детально изменены блоки: датчики на оборудовании, edge-шлюз, ML-модель, платформа maintenance, диспетчер.
- **UC7 Управление логистикой и складом.svg**: Изменены на MES, датчики запасов, RFID, поставщиков.
- **UC8 Экологический мониторинг и энергоэффективность.svg**: Изменены на датчики CO2/энергии, edge-анализ, BMS оптимизация.
- **UC9 Интеграция с городскими системами.svg**: Изменены на городские API, корреляцию с BMS, ЭЗС.
- **UC10 Бизнес-аналитика и отчетность для менеджмента.svg**: Изменены на аналитику KPI, ERP интеграцию.
- **архитектура IIoT.svg**: Добавлены метки IIoT, цифровые двойники, MES/ERP.
- **протоколы IIoT.svg**: Добавлены Profinet, TSN, EtherCAT.

## UI (docs/ui/)
- **maintenance-dashboard.svg**: Изменены навигация (Обслуживание, Оборудование, Алерты), метрики (оборудование, вибрация, алерты), пользователь (техник обслуживания).
- **inventory-dashboard.svg**: Изменены навигация (Запасы, Заказы, Поставки), метрики (запасы, заказы, сроки), пользователь (складской менеджер).
- **eco-dashboard.svg**: Изменены навигация (Экология, Оптимизация, Датчики), метрики (CO2, энергия, выбросы), пользователь (эко-специалист).
